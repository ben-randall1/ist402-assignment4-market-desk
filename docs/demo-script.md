# 45–55 second demonstration guide

1. 0–15s: Show Live feed, AAPL/BTC-USD, moving price/candles, corresponding volume,
   source age and Yahoo status. Identify five-second candles and the provisional interval.
2. 15–25s: Show the receipt journal changing and the persistent SQLite receipt/version counts.
   Explain that source and receipt times are stored separately.
3. 25–40s: Click Replay record. Point out the RECORDED REPLAY banner and advancing cursor;
   explain that replay uses only the receipt prefix and retains revisions.
4. 40–50s: Return to Live feed, then Test feed disconnect. Show unavailable status and
   retained chart. Explain that duplicate receipts are recorded without double counting.
5. Reconnect after recording. Record only the application window; exclude account information.

The required video must last 30–60 seconds and be accessible to the instructor.
Do not claim synthetic tests or recorded playback establish live Yahoo connectivity.
